## 📖 О проекте

Сайт-презентация HTML Academy - лучшей платформы для обучения программированию. Проект демонстрирует преимущества обучения на платформе через современный и адаптивный веб-дизайн.

## ✨ Особенности сайта

- 🎨 **Быстрое обучение** - базовый курс за 20 часов
- 📱 **Полностью адаптивный дизайн** - оптимизирован для всех устройств
- ⚡ **Современный CSS** - flexbox, градиенты, адаптивная верстка
- 🎯 **Интерактивные элементы** - кнопки с hover-эффектами
